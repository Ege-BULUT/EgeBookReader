# Roadmap

## Done on Android

Reader, page turning, themes, typography, actual book mode, image filters, colorization, read aloud, picture viewer, all common formats, right-to-left reading, the webtoon strip, and a library with favourites, lists, categories, tags, sorting, filters and book details (0.1.7).

## Next

1. **Interface languages.** English and Turkish today. Then Russian, Arabic, Chinese, Japanese, Korean, German, French and Hindi.
2. **Manga and manhwa support.** Right-to-left reading (0.1.4) and the webtoon strip (0.1.5) are done. Next: panel-by-panel navigation and comic-aware page layout.
3. **More platforms.** iOS, Windows, macOS and Linux from the same code.
