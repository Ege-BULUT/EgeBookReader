# Roadmap

## Done on Android

Reader, page turning, themes, typography, actual book mode, image filters, colorization, read aloud, picture viewer, and all common formats.

## Next

1. **Interface languages.** English and Turkish today. Then Russian, Arabic, Chinese, Japanese, Korean, German, French and Hindi.
2. **Manga and manhwa support.** Right-to-left reading is done (0.1.4). Next: vertical strip mode for webtoons, panel-by-panel navigation, and comic-aware page layout.
3. **More platforms.** iOS, Windows, macOS and Linux from the same code.
