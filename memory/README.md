# EgeBookReader knowledge base

Read this first in every session. Start at the top; go deeper only for the topic at hand.

| file | what it holds |
|-|-|
| `brief-original.md` | The user's brief, verbatim. The source of truth. |
| `requirements.md` | The brief as numbered requirements (R0–R9). Tasks and commits cite these ids. |
| `decisions.md` | Dated decision log (append-only). |
| `open-questions.md` | What still needs the user's call, with a recommendation each. |
| `research/stack.md` | App architecture: Rune, Flutter, Compose MP, Tauri 2 and others; reference readers. |
| `research/formats.md` | Ebook formats, rendering engines, licenses, PDF reflow, text shaping. |
| `research/page-turn.md` | Procedural page curl, Okuma-Reader filters, tap zones, volume keys. |
| `research/fonts-design.md` | Font providers and APIs, custom fonts, reading themes, design and motion rules. |
| `research/image-ai.md` | On-device colorize and upscale models, runtimes, background-queue strategy. |
| `research/tts.md` | On-device TTS models (languages, sizes, licenses, URLs), system TTS, cloud APIs. |

Project tracking (roadmap, Kanban, agent journals) is in `../openlead/` — open `../openlead/index.html`.
